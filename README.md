# Notch Heart · 刘海旁的小红心

为 macOS 上的网易云音乐提供一个独立悬浮的收藏按钮。放在刘海左侧或下方，不占右侧菜单栏位置。

## 使用

1. 双击 `dist/Notch Heart.app`。建议在授权前把应用放到一个固定位置。
2. 首次打开，在设置窗口点击「打开辅助功能设置」，在 macOS 的辅助功能列表中允许 **Notch Heart**。如果未出现，可按 `+` 添加这个 `.app`。
3. 在网易云音乐里播放一首歌曲。空心表示可以喜欢，红心表示客户端报告已喜欢，斜线心表示未连接或状态未知。
4. 单击红心收藏；已喜欢时不会再次切换。右键可取消喜欢、切换位置、打开设置或退出。
5. 拖动按钮可保存自定义位置；屏幕变化时会限制在可见屏幕内。刘海左侧不是系统预留槽位，菜单较长时请切换到「刘海下方」。

平时不显示 Dock 图标和额外菜单栏图标。重新打开应用可恢复按钮位置并显示设置。

## 心形背景（0.2.0）

右键红心 →「心形背景」，或在设置窗口选择：

- **亚克力**：系统原生模糊材质（`NSVisualEffectView`），默认样式。
- **透明**：只显示心形，不绘制底色和边框。
- **液态玻璃**：macOS 26 的原生 `NSGlassEffectView`。旧系统禁用此选项；若保存的玻璃偏好在旧系统打开，则回退到亚克力。

选择即时生效并保存，重启后保持；演示模式的偏好独立。系统的减少透明度等辅助功能设置可能影响材质呈现。

## 构建

运行需要 macOS 13+；构建完整液态玻璃支持需要 Xcode 26 / macOS 26 SDK 与 Swift 6.2+。旧工具链可构建仅支持亚克力和透明的兼容版本。没有第三方依赖。

```sh
swift run HeartCoreChecks
bash scripts/build-app.sh
open "dist/Notch Heart.app"
```

产物为当前 CPU 架构的 `.app` 和 ZIP。本地临时签名用于自行构建，不是 Developer ID 公证发行包。重新构建后，如系统不再识别原来的辅助功能授权，需要从辅助功能列表移除旧条目并重新添加。

## 演示模式

```sh
open -n "dist/Notch Heart.app" --args --demo
```

演示模式不读取或操作网易云，位置设置也与实际模式隔离。适用于验证点击反馈、重复点击、拖动和跨应用显示。不要同时运行多个真实模式实例。

## 本地控制方式

- 用 AppKit 的非激活 `NSPanel` 绘制按钮；普通收藏不会主动激活任何应用。
- 用 `NSScreen.auxiliaryTopLeftArea` / `auxiliaryTopRightArea` 定位刘海两侧。
- 只读取 `com.netease.163music` 的原生「控制」菜单，通过辅助功能 `AXPress` 执行「喜欢歌曲 / 取消喜欢」。不会模拟全局快捷键，不依赖固定坐标。
- 依据精确菜单动作名称和原生勾选标记判断状态；禁用或未知菜单不操作。
- 点击前重新读取状态。发送后轮询确认；失败或超时不会自动重发。未确认时锁定后续操作，需用户检查客户端后显式解锁。
- 不读取账号、Cookie 或歌曲数据库，不请求屏幕录制，不使用网易云私有 HTTP API，不联网、不上传数据。

## 当前范围与限制

- 当前适配依据是网易云音乐 Mac 3.1.12 的原生菜单和中英文动作名称。不同版本需重新验收。
- 红心依据的是本地客户端的状态，并不能独立证明服务器同步已完成。
- 原生菜单未提供稳定的歌名/歌曲 ID，因此目前提示「当前歌曲」，不猜测歌名。歌曲在按下瞬间切换时，操作对象由网易云客户端决定。
- 刘海左侧可能与较长的应用菜单重叠；本版提供下方位置和手动拖动，不包含自动菜单碰撞检测。
- 配置了跨 Space / 全屏辅助窗口行为，但实际表现仍需对目标系统、全屏应用和外接显示器验收。
- 不包含开机启动、全局快捷键、菜单栏折叠或云端收藏接口。

## 测试

`swift run HeartCoreChecks` 覆盖菜单状态判别、重复点击、超时防重试、显式解锁、负坐标显示器、刘海遮挡和移出屏幕后的恢复。

真实环境验收：

- [x] 未授权时明确显示权限状态；重新授权最终构建后可读取当前收藏状态。
- [x] 通过悬浮按钮实际收藏，网易云自身菜单变为「取消喜欢」。
- [x] 第二次点击不取消收藏。
- [x] 右键取消喜欢在隔离演示中有效；真实取消收藏尚未测试。
- [ ] 不同前台应用的输入焦点保持情况逐一验收（代码不主动激活网易云）。
- [ ] 网易云暂停、最小化、退出时行为符合提示。
- [ ] 网络异常 / 操作未确认时不显示成功，不重复切换。
- [ ] 长菜单、全屏、Spaces、外接屏和睡眠唤醒下可找回按钮。
